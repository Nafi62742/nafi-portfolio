# 🎨 Visual Media & Carousel Creation Guide: The Tech Creator Toolkit

Text-only posts work for short hot-takes, but for showcasing software projects, **visual proof is non-negotiable**. Posts with short demo videos, high-contrast architecture diagrams, or PDF carousels get up to **300% more reach and dwell time**.

Here are the free tools, ideal dimensions, and step-by-step blueprints to craft top-tier visuals.

## 2. 📱 Ideal Visual Dimensions for LinkedIn

To ensure your images and videos don't get cropped awkwardly on mobile feeds:

- **PDF Carousels (Documents):** **1080 × 1350 px** (4:5 vertical aspect ratio). This takes up the maximum vertical screen space on mobile phones! (Square **1080 × 1080 px** also works well).
- **Single Image (Architecture / Mockup):** **1200 × 675 px** (16:9 landscape) or **1080 × 1080 px** (1:1 square).
- **Video Demos:** **1:1 square** (1080 × 1080 px) or **16:9 landscape** (1920 × 1080 px). Keep videos between **15 and 45 seconds**. Autoplay is on by default with no sound, so ensure action starts within the first 2 seconds!

## 3. 📑 How to Make an 8-Slide Tech Carousel in Canva / Figma

Carousels are uploaded to LinkedIn as **PDF Documents** (click the "Add a document" icon when creating a post). LinkedIn automatically renders them as a swipeable presentation.

### The Proven 8-Slide Tech Case Study Blueprint:

```text
┌──────────────┐  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│   Slide 1    │  │   Slide 2    │  │   Slide 3    │  │   Slide 4    │
│  Bold Title  │  │ The Problem  │  │ Architecture │  │ Deep Dive 1  │
│    + Hook    │  │  Constraint  │  │   Diagram    │  │  Code/Logic  │
└──────────────┘  └──────────────┘  └──────────────┘  └──────────────┘
┌──────────────┐  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│   Slide 5    │  │   Slide 6    │  │   Slide 7    │  │   Slide 8    │
```

#### Example Carousel Concept: *"Surviving Battery Killers in Flutter GPS Apps"*
- **Slide 1:** Large bold text: *"How We Kept Real-Time GPS Tracking Alive on 10,000+ Android Devices"* + Nafi Ahmed, Core Developer.
- **Slide 2:** *"The Nightmare:"* Chinese Android OEMs terminate background threads after 180 seconds to save 1% battery.
- **Slide 3:** High-level diagram showing the persistent foreground service + dead reckoning fallback.
- **Slide 4:** Snippet of code handling local recovery state and wake-locks safely.
- **Slide 5:** Multi-window velocity anti-cheat algorithm breakdown.
- **Slide 6:** Results: 0 drop-outs reported across 4 official marathons.
- **Slide 7:** Top 3 lessons learned for mobile developers.
- **Slide 8:** *"Enjoyed this breakdown? Follow @Nafi Ahmed for more mobile & full-stack architecture insights. Check out RunMate Club on iOS & Android."*

## 4. 🎬 Best Practices for Video Demos

1. **Start directly with the action:** Don't start with a blank splash screen or a login page. Start with the map rendering, the live bid counting down, or the dashboard loading.
2. **Add subtle captions or arrows:** 80% of LinkedIn users watch video without sound.
3. **Keep it under 60 seconds:** 20–35 seconds is the sweet spot for completion rate metrics.
4. **Export in high bitrate:** Use 1080p MP4 format.
