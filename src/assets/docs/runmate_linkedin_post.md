### 💡 Core Engineering Highlights:

1. **🔋 Battery-Hardened Background GPS Engine**:
   - Engineered persistent tracking resilient against aggressive OEM battery managers (Oppo, ColorOS, Xiaomi) and OS process kills.
   - Real-time road-snap accuracy, auto-pause/resume, and continuous voice coaching per kilometer that survives backgrounding.

2. **🛡️ 3-Layer Anti-Cheat & Region-Scoped Leaderboards**:
   - Multi-window velocity filters, teleport detection, and dead-reckoning gap handling for fair regional competition.
   - Leaderboards automatically scope based on runners' recent routes.

3. **🏅 Official Marathons & Virtual Run Challenges**:
   - Category-based KML route mapping, live racer position broadcast during official races, and bib allocation.
   - Remote Virtual Run distance challenges with deadline tracking and auto-generated RFID / milestone completion certificates.

4. **👥 Running Clubs & Social Community**:
   - QR-code club invites, social activity feeds, cheers, route cards, and multilingual support (**English, Bengali, and Japanese**).

5. **🏢 Organizer & Web Admin Command Center**:
   - Multi-merchant **SSLCommerz** ticket fee routing, registration review queue, live fleet map telemetry, and organizer self-signup workflows.

## 💻 Option 3: Deep-Dive Engineering / Architecture Post

🛠️ **Engineering RunMate Club: Surviving OEM Battery Killers & Real-Time Race Telemetry at Scale**

When building a high-precision running and marathon app, standard location APIs often fail under edge conditions: aggressive OEM battery management killing background threads, GPS drift, or intermittent mobile connectivity mid-race.

Here’s how our team at **XORGeek** (in collaboration with **Nymph Solution**) tackled these technical challenges:

🔹 **Background Location Hardening**: Configured persistent background services that survive OEM process terminations (ColorOS, MIUI, etc.) with local dead-reckoning state recovery.
🔹 **Anti-Cheat Pipeline**: Multi-window velocity filters and teleport detection to maintain fair regional leaderboards.
🔹 **Sub-Second Fleet Sync**: Firebase Realtime Database and Cloud Functions for live bib tracking during official marathons.
🔹 **Multi-Tenant Payments**: SSLCommerz multi-merchant credential routing so race organizers receive ticket sales directly.

Proud to have worked as **Core Developer** on this build alongside **Masum Reza** (Team Lead), **Razin Sufian**, **Kawsar Ahmed**, and **Mohammad Abir Hassan Sarker**!
